# Calculadora de Consumo Diário de Água

Aplicação web progressiva (PWA) desenvolvida para calcular a recomendação diária de ingestão hídrica baseada em critérios clínicos por faixa etária e peso corporal.

---

### Aceder à Aplicação
[Clique aqui para abrir o App no Netlify](https://spectacular-figolla-b1472f.netlify.app)

---

### Critérios Clínicos Adotados
* **Jovens (até 17 anos) — 40 ml/kg:** Demanda hídrica elevada e taxa metabólica basal acelerada.
* **Adultos (18 a 64 anos) — 35 ml/kg:** Padrão de referência para homeostase celular e depuração renal.
* **Idosos (65+ anos) — 30 ml/kg:** Ajuste fisiológico para prevenção de sobrecarga renal e controlo hídrico.

---

### Tecnologias Utilizadas
* **C:** Desenvolvimento e validação da lógica algorítmica inicial.
* **HTML5 & CSS3:** Interface responsiva com padrão visual clínico.
* **JavaScript:** Manipulação do DOM e cálculo em tempo real.
* **PWA (Progressive Web App):** Suporte de instalação no ecrã inicial via `manifest.json` e `sw.js`.
